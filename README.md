

## Python icon generation

Use Python 3.13.18 in a project-local environment: `py -3.13 -m venv .venv`, then `.\.venv\Scripts\python.exe -m pip install -r requirements-icons-lock.txt`. Run `run-icons.cmd` to generate launcher icons. See [the security update](docs/python-security-update-20261026.md) for validation details.
